# Sample Electricity Bill Dataset

## Overview
This folder contains sample electricity bill data for the SmartEnergy AI project.

## Dataset Fields
- month: Billing month in YYYY-MM format.
- units: Electricity consumed in units (kWh).
- amount: Electricity bill amount.
- due_date: Bill payment due date.

## Purpose
The sample dataset can be used for testing, demonstrations, and understanding electricity consumption trends.

## Important Note
The included records are illustrative sample data and are not actual consumer bills or official electricity provider records.
